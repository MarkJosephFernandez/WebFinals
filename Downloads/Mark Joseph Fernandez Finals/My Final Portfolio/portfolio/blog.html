01

HTML & CSS

I use semantic HTML to organize a page and Flexbox to arrange its content. I'm learning how the document structure affects accessibility and how layouts adapt to smaller screens.

On this portfolio, project cards stack vertically on small screens. On wider screens, CSS Grid places them side by side. I use object-fit: contain to keep previews uncropped inside their frames.

02

Java

I use object-oriented programming in my coursework to organize code into classes. I'm also practicing algorithms and data structures.

For a campus guide, I can model a room with a Room class containing its name, building, and floor. An ArrayList<Room> could hold the rooms to display. This is a practice example of keeping related data together instead of maintaining separate lists for each field.

03

MySQL

I practice designing normalized database schemas and writing SQL queries. I'm learning how table relationships affect the way I store and retrieve data.

In a practice schema for a campus guide, I can keep buildings and rooms in separate tables. Each room would reference a building through building_id. The query SELECT name FROM rooms WHERE building_id = 1; would list the room names for one building without repeating its details in every room record.

04

JavaScript

I use JavaScript for browser interactions. On this site, the mobile menu updates its expanded state and closes when I press Escape.

I also use JavaScript to keep the footer year current. The script reads new Date().getFullYear() and updates the elements marked with data-year. The HTML includes a fallback year, so the footer still has content when JavaScript is unavailable.

05

Node.js

I use Node.js to practice running JavaScript on the server. I'm learning how to handle requests and move data through an application.

As a practice example, I could build a GET /api/rooms/101 endpoint that looks up a room by its ID. It could return { "id": 101, "name": "Lab A" } when the room exists, or a 404 response when it does not. This gives me a small exercise in reading a request and choosing the appropriate response.

06

PHP

I'm learning PHP as another language for web development. It runs on the server and can process form submissions before sending a response to the browser.

For a practice exercise, I could build a form that accepts a room name and building. The PHP handler would check that both fields are present and return a useful error if either is missing. This would help me practice validating data on the server.

07

CodeIgniter

I'm also learning CodeIgniter, a PHP framework. Its model-view-controller structure gives me a way to separate data access, request handling, and page templates.

For a practice room directory, I could use a model to retrieve room records, a controller to handle the request, and a view to display the list. That would let me change the page layout without putting database queries in the template.
